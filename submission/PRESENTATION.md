# Project demonstration

The public demo presentation contains **seven slides, including the title**:

- [View the presentation (PDF)](https://triagesar.devdragons.lk/demo/TriageSAR-7-Slide-Demo.pdf)
- [Download the editable PowerPoint](https://triagesar.devdragons.lk/demo/TriageSAR-7-Slide-Demo.pptx)

The minimal deck uses screenshots captured from the released application on 15 November 2026. It covers
the five case studies, quality screening, the Kumamoto inspection queue, the score audit, limited coverage,
provenance and limitations. The slide count includes the cover and closing slide.

SI disclosure is visible on each slide. Screenshots show the actual application; scientific observations
come from NASA/ISRO NISAR via ASF DAAC. Roads are credited to OpenStreetMap contributors and basemaps to
NASA GIBS. The PowerPoint's speaker notes contain source links and context for each slide.

Use the PDF URL in the NASA Space Apps **Project Demonstration** field. The longer screen recording can
remain supplementary material; this seven-slide deck is the short demonstration.
